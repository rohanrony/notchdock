October 05, 2026
Added
  • Delete NotchDock-Created Reminders Lists: Folders created in NotchDock can now be deleted directly from NotchDock, which also deletes the corresponding list in Apple Reminders via EventKit (`EKEventStore.removeCalendar`) without re-import loops (`ToDoWidget.swift`, `ToDoRemindersSync.swift`).
  • Added `isNotchDockCreated`: tracking on `ToDoFolder` to distinguish folders created in NotchDock from external lists imported from macOS Reminders.
  • Deleting a: NotchDock-created folder automatically pushes calendar removal to Apple Reminders via `pushDeleteList`.
  • External lists: imported from macOS Reminders remain protected from accidental deletion in NotchDock (providing Shown/Hidden visibility controls instead).
  • Added unit: tests `testToDoNotchDockCreatedLinkedFolderCanBeDeleted` and `testToDoFolderCanDeleteProperty`.
  • ToDo Widget Apple Reminders Sync & Urgency Grouping: Integrated two-way macOS Reminders synchronization and sports-style relative accordion grouping (`ToDoWidget.swift`, `ToDoRemindersSync.swift`, `SharedEventStore.swift`).
  • Added seamless: two-way integration with Apple Reminders via `EventKit` (`EKEventStore`), mapping ToDo folders to native Reminders lists.
  • Implemented 100%: backward-compatible decoding with zero data loss for existing users, smoothly preserving local Keychain tasks and optionally syncing them to Reminders.
  • Fully automated two-way synchronization: automatic pull on widget expand, app active lifecycle observation, and 30-second periodic background timer for seamless cross-device iCloud synchronization without manual triggers.
  • Added support: for due dates and times with relative badges (`Overdue`, `Today`, `Tomorrow`, `This Week`, `Later`), and an imminent countdown timer badge (`⏱ in 35m`) for tasks due within 2 hours.
  • Added a: sort switcher allowing users to toggle between Urgency sort (due date priority) and classic manual drag-and-drop order.
  • Designed Sports-style: accordion day & week groups (`Due`, `Today`, `Tomorrow`, `This Week`, `Later`, `Completed`) with rotating chevrons, count badges, and cross-day drag-and-drop rescheduling.
  • Integrated Apple: Reminders connection into the first-launch Setup Assistant (Onboarding flow) alongside Keychain authorization.
  • Added Apple Reminders Sync status in `ToDoSettingsView` with live activity indicator (`Automatic: Live`).
  • Comprehensive unit: test coverage in `notchdockTests.swift` (`testToDoLegacyDecoding`, `testToDoRelativeGrouping`, `testToDoUrgencySorting`, `testToDoDragPermissionsInUrgencyMode`, `testToDoRemindersPureMerge`, `testToDoRemindersAutomaticSyncProperties`).
  • Timer Widget Pomodoro & Standard Quick Presets: Added intuitive 1-click rhythm preset pills directly into the expanded notch panel and Settings view (`TimerWidget.swift`).
  • Added Pomodoro: preset pills (`[ 15/3 ] [ 25/5 ] [ 50/10 ] [ 90/20 ]`) positioned right beside the time display in `TimerExpandedView` when Pomodoro mode is active.
  • Supported four standard focus workflows: Sprint (`15m` focus, `3m` break), Classic Pomodoro (`25m` focus, `5m` break), Deep Work (`50m` focus, `10m` break), and Ultradian Flow (`90m` focus, `20m` break).
  • Tapping a: preset pill dynamically highlights the active rhythm with `ThemeTokens.accentColor` border stroke and immediately updates focus, break, and cycle settings in idle, running, and paused/completed states.
  • Expanded focus: duration upper bounds from 60m to 90m across Pomodoro view model, direct input text editors, stepper controls, and `AppleTimerSlider` progress dragging to smoothly support full 90-minute ultradian deep work blocks.
  • Added Quick: Presets card and pill selectors in `TimerSettingsView` allowing users to quickly configure default standard durations (`[ 1m ] [ 5m ] [ 15m ] [ 25m ] [ 50m ]`) and default Pomodoro intervals.
  • Comprehensive unit: test coverage in `notchdockTests.swift` (`testPomodoroPresetsApplicationAndCustomRhythms`) testing idle and active state switching, duration clamping, break adjustments, and custom cycle overrides.
  • Updated widget: documentation in `notchdock/docs/apps/timer-widget.md`.
Improvements
  • ToDo Reminders List Protection: Folders imported from macOS Reminders are protected from accidental deletion within NotchDock (providing Shown/Hidden visibility controls instead), preventing accidental data loss outside the app and avoiding re-import loops (`ToDoWidget.swift`).

Version 0.17.2

September 28, 2026
Added
  • Timer Widget Pomodoro Focus Companion: Integrated a native, minimalist Pomodoro focus sprint mode into the Timer widget (`TimerWidget.swift`).
  • Added an: inline mode switch (`[ Timer | 🍅 Pomodoro ]`) allowing seamless toggling between basic countdown timers and structured interval sessions.
  • Implemented an interactive setup tray with 3 configurable parameter chips: Focus sprint duration (1–60m), Break duration (1–30m), and Cycle count (1–8 cycles), adjustable via inline `− / +` micro-steppers, direct numeric input, or custom Apple-style slider dragging.
  • Built an: ambient running session HUD with phase indication (`🎯 Focus • Cycle X of Y` vs `☕ Break • Cycle X of Y`), dynamic cycle progress dots (`● ● ○`), and color-coded progress track (Sage Green for work sprints, calming Sky Blue for rest breaks).
  • Implemented Option B phase transitions: plays a double chime on focus completion and automatically pauses at break duration with an auto-expanding notch prompt, allowing users to manually begin breaks when ready (with configurable "Auto-Start Breaks" toggle in Settings).
  • Added explicit: minimal outline action buttons (`[ ▶ Start Break ]`, `[ ▶ Start Focus ]`, and `[ ✓ Done ]`) with 1px accent outline, transparent background, and no glow or gradients.
  • Eliminated trailing breaks: $N$ cycles execute exactly $N$ focus sprints and $N - 1$ breaks, concluding the session immediately upon completing the final focus block.
  • Implemented two-way connected manual time editing: minutes-only editing in Pomodoro mode with seconds locked to `:00`, real-time bidirectional synchronization with setup chips and slider, unambiguous parameter binding (`editingParameter`), and automatic commit on blur or loss of focus.
  • Added a: dedicated Skip button (`forward.end.circle.fill`) to conclude focus or break blocks early without resetting session state.
  • Enhanced the compact notch island with phase-specific glyphs (`brain.head.profile` vs `cup.and.saucer.fill`) and live cycle countdowns (`1/3 • 24: 50`).
  • Anchored timer countdowns to wall-clock `targetEndTime: Date?` with `NSWorkspace.didWakeNotification` listeners, ensuring complete accuracy across macOS system sleep and screen locks.
  • Added unit: test suite in `notchdockTests.swift` covering mode switching, cycle transitions, Option B manual pausing, skip actions, session completions, and manual time edit consistency (`testPomodoroModeAndDefaults`, `testPomodoroCycleProgressionAndOptionB`, `testPomodoroCompletionAndSessionReset`, `testPomodoroSkipAndReset`, `testPomodoroManualTimeEditConsistency`).
  • Updated widget: documentation in `notchdock/docs/apps/timer-widget.md` and Setup Assistant directory in `WidgetGuide.swift`.
  • Stocks Widget Ticker Not Found & Timeout Handling: Added graceful failure handling for invalid, delisted, or unfound stock tickers in the Stocks expanded panel.
  • Replaced indefinite: spinner searching with a 6-second timeout safeguard and immediate error detection on Yahoo Finance 404 or empty chart responses.
  • Implemented `StockNotFoundRow`: displaying a soft-red ticker badge, a clear `"Symbol not found"` warning indicator, an inline Retry (`arrow.clockwise`) action, and a prominent 1-click Delete button (`trash.fill` + `"Delete"`) to easily remove invalid symbols from the watchlist.
  • Implemented `StockLoadingRow`: with an active `"Searching quote..."` indicator and a hover `"Cancel"` button to discard a mistyped symbol immediately without waiting.
  • Added `Not: Found` status labeling in the Settings window's Tickers list and automated test coverage in `notchdockTests.swift` (`testStocksTickerNotFoundAndTimeoutHandling`).
Fixed
  • Pomodoro Stepper Time Reduction & Parameter Isolation: Resolved an issue where clicking `−` or `+` steppers occasionally failed to reduce time or reverted immediately due to stale `applyChanges()` re-evaluations during state changes.
  • Eliminated rogue `onChange(of: isEditing)` watcher and guarded `applyChanges()` strictly with `guard isEditing else { return }`, ensuring micro-stepper decrements/increments and direct numeric modifications never get overwritten by uncommitted stale string state.
  • Fixed focus: time leaking into break time (and vice-versa) when manually editing text and tapping another parameter chip or stepper by committing active edits to the originating parameter before transitioning, resetting `editingParameter = nil`, and immediately populating `editMinutes` with the target parameter's own duration.
  • Expanded hit-box: targets for `PomodoroParameterChip` micro-steppers (24×27pt) with tactile scale animation (`0.88`), crisp hover tinting, and reliable click response.
  • Added unit: test verification (`testPomodoroIndependentParameterSteppingAndIsolation`) in `notchdockTests.swift` validating independent stepping down of focus, break, and cycle values without cross-parameter pollution.
