Quick Access

Keep reusable text snippets in NotchDock Quick Access

Create a short list of labeled text you choose to save, then copy an item from the expanded notch panel when you need it.

A saved snippet list, not automatic clipboard history

Quick Access keeps text entries that you add and edit, such as a reusable reply, a command, or a project identifier. It does not collect every item you copy from other apps. Add only the text you intend to keep in this list.

Add, edit, and copy an item

  1. Open the Quick Access widget and choose Add Item to Quick Access Clipboard.
  2. Enter a label and the text in the new row. Edit either field directly when the text changes.
  3. Hover a row to reveal its copy and delete controls. Choose Copy to put that item on the macOS pasteboard.

The expanded panel shows your saved rows; the compact widget can show the number of items.

Authorize storage

Quick Access Settings includes a Keychain Access control. If the app asks for access, choose Grant Access there. The current implementation saves the Quick Access items through the macOS Keychain helper and can migrate existing saved items from its earlier app storage.

Quick Access is a convenience list, not a password manager. Follow your organization’s rules before saving credentials or sensitive information in any clipboard or snippet tool.

Common questions

Does it save my entire copy history?

No. Quick Access contains entries you add to the list; it does not automatically monitor the system clipboard.

How do I remove an item?

Hover its row and choose the delete control. This removes the saved entry from Quick Access.

Can I paste an item into another app?

Choose the row’s copy control, then paste in the other app using the usual macOS paste command.
