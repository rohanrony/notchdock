Glanceable Widget Updates

Use NotchDock for glanceable widget updates on Mac

NotchDock puts selected information and controls in widgets around the MacBook notch. It works alongside macOS notifications; it does not replace, intercept, or suppress them.

A widget surface, not a notification filter

Use NotchDock to check a supported widget when you want a glance at a score, quote, timer, or currently playing track. Each widget has its own update source and controls. NotchDock does not turn off macOS notification banners or promise that every widget update is silent.

To choose which apps can show system notifications, use macOS System Settings under Notifications and Focus. NotchDock does not change those system settings for you.

Permissions and data depend on the widget

  • Sports: match schedules and scores are requested from ESPN. Available leagues and fixtures depend on the feed.
  • Stocks: ticker symbols and search terms are sent to Yahoo Finance to find quotes and history. Timing and availability depend on the provider.
  • Music: NotchDock uses macOS automation access to read and control supported players. Spotify and Kaset may supply artwork URLs that NotchDock fetches for display.
  • Timer: the timer can sound a chime at phase completion. It is not a silent replacement for alerts.

These widget-specific behaviors are separate from macOS Notification Center. Review the linked feature pages for the relevant setup and data details.

Common questions

Does NotchDock replace or suppress macOS notifications?

No. NotchDock widgets are a separate place to view supported information and controls. They do not replace Notification Center or suppress system notification banners.

Are NotchDock updates always silent?

No. The Timer widget plays a chime when a timer phase completes. NotchDock is not a system-wide notification filter, and this page does not promise silent behavior.

Where does widget information come from?

The Stocks widget sends ticker searches and quote requests to Yahoo Finance. The Sports widget requests schedules and scores from ESPN. The Music widget uses macOS automation for supported players, and some artwork can be fetched from a player-provided URL. See each feature page for details.
