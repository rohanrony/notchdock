Connect the separate Kaset player to NotchDock

NotchDock does not install or provide a YouTube Music desktop client. Kaset is a separately maintained player that appears in the Music widget when available.

Set up a Kaset playback check

  1. Review the Kaset project and current releases for its own installation requirements.
  2. Open Kaset and start a track.
  3. Open NotchDock’s Music widget and check that the current item and available controls appear.
  4. Try play/pause and track navigation. Do not expect seeking; the NotchDock Kaset integration does not support it.

Kaset is a separate app; its sign-in, playback, and account behavior are governed by that project. Some artwork is loaded from a player URL and may require a network connection.

See NotchDock’s current Music widget support.

NotchDock is currently free during beta and requires macOS 14 or newer.
