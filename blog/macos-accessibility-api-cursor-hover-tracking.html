Review NotchDock permissions in macOS

NotchDock’s earlier claim that it needs Accessibility access for global cursor tracking was not verified. This guide describes the permission areas present in the reviewed app and how to review access in macOS.

Accessibility permission is not established here

The reviewed Swift source handles notch entry with AppKit tracking areas and SwiftUI hover events. A bounded search found no CGEventTap, global NSEvent monitor, or Accessibility API cursor tracker. Do not grant Accessibility access just because an old NotchDock guide asked for it.

Review the permission the widget actually needs

Calendar and Reminders widgets use Apple’s EventKit store and request the corresponding access when connected. Quick Notes automation interacts with Apple Notes and can trigger macOS Automation consent. Keychain-backed Quick Access and ToDo data use Keychain APIs. Check the prompt and the relevant list under System Settings > Privacy & Security; disable access if you no longer use the feature.

Apple explains how to control calendar access, how to review Privacy & Security settings, and how to manage app automation access.

Use the prompt and privacy policy as your source

Permission requirements can differ by widget and macOS version. Read the text macOS presents, check the installed release’s settings, and consult the NotchDock privacy policy. This page does not claim that the app uses a system-wide cursor event tap or needs the broad Accessibility grant.
