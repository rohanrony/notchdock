Securing Clipboard History: Handling API Keys, Passwords & Secrets on Mac

Copying an AWS secret key or database connection string into a clipboard history tool can be dangerous. Here is how NotchDock automatically filters and purges sensitive tokens.

Direct Answer: How does NotchDock prevent sensitive API keys and passwords from being saved in clipboard history?

NotchDock integrates with the macOS Pasteboard Concealed Types specification (org.nspasteboard.ConcealedType). When you copy credentials from 1Password, Bitwarden, or Keychain, NotchDock automatically excludes them from history. Furthermore, heuristic regex detectors flag potential AWS, GitHub, and OpenAI API tokens for instant manual purging.

1. Concealed Pasteboard Types in AppKit

Password managers tag copied strings with special concealment markers. NotchDock respects these markers strictly, ensuring master passwords never enter searchable history.

Step-by-Step Setup Guide

  1. Step 1: Enable 'Concealed Type Filtering' in NotchDock Settings.
  2. Step 2: Copy credentials safely from your password manager.
  3. Step 3: Rest assured your sensitive secrets remain protected.
