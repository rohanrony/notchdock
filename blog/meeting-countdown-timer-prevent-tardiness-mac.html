Fix Missing Calendar Events or Meeting Links in NotchDock

If Calendar is empty or Join Meeting is missing, check permission first, then confirm the relevant calendar is enabled and the event has a supported HTTPS link.

Troubleshoot Calendar access and Join Meeting

  1. Check Calendar permission. In the Calendar widget, use the access prompt to allow access. If access was denied, open Apple menu > System Settings > Privacy & Security > Calendars and enable NotchDock. Apple explains these controls in its calendar access guide.
  2. Check Visible Calendars. Open Calendar Settings in NotchDock and confirm the calendar containing the event is selected. If no calendars are enabled, the widget has no events to show.
  3. Check the invite link. Select the event and inspect its details. Join Meeting requires an HTTPS URL in the event URL field, or a recognized Zoom, Google Meet, Teams, or Webex URL in its notes.
  4. Check the start time. The button appears only while the event is in progress or during the 10 minutes before it starts. Events without a recognized link can still appear without a join button.

The Calendar widget reads events available through macOS Calendar. It does not repair missing invitations, add conferencing links, or bypass an account’s calendar permissions. If you need the normal viewing workflow, see Show your next meeting and join link in NotchDock.

NotchDock is currently free during beta and requires macOS 14 or newer.
