Where NotchDock stores settings, snippets and widget data

“Local-first” does not mean every widget is offline or every kind of data shares one storage system. The reviewed source uses different macOS facilities for preferences, saved snippets, notes integration, and system calendars.

Different data uses different storage

  • Preferences: Widget order, enabled widgets, display choices, and other settings use namespaced UserDefaults keys.
  • Quick Access: The user-managed snippet list is encoded and saved using the Keychain helper. It is not an automatic clipboard history.
  • ToDo: Folder/task data uses the Keychain helper, with migration paths for older local data.
  • Quick Notes: The app keeps a local cache in UserDefaults and can interact with Apple Notes after macOS Automation permission is granted.
  • Calendar and Reminders: The widgets use EventKit and the user’s macOS permission. Any iCloud synchronization is controlled by the Apple account and system apps, not a NotchDock cloud database claim.

This source review did not find SQLite or Core Data storage in the NotchDock Swift project. That is a bounded code observation, not a statement about every third-party framework or release artifact.

Local settings do not make live feeds offline

Sports and market widgets request data from external providers and need a network connection. When offline, saved preferences can remain local while current scores or prices may be unavailable or stale. The privacy policy describes the website and app data boundaries.

How to review your setup

  1. Open System Settings > Privacy & Security and review the Calendar, Reminders, Automation, and other permissions you have granted.
  2. Check the feature settings in the installed app and disable integrations you do not use.
  3. For a work or travel device, test the exact widget with the network disconnected and record which parts still function.

No JSON backup, cross-device NotchDock sync, or guaranteed fully offline operation is claimed here.
