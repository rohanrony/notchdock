Product Overview

A notch workspace for supported Mac workflows

NotchDock places a set of small, interactive widgets around the MacBook display notch. Open the expanded panel when you need a control or detail, then use each widget for the task it supports.

Supported workflows

Choose the widget for the task

Each feature has its own controls, setup, and data sources.

Follow a stock watchlist

Create named lists, pin tickers, and review price changes and history charts. Search and quote requests use Yahoo Finance, so ticker queries are sent to that provider. The widget does not calculate portfolio P&L or send threshold alerts.

Stock watchlists and charts

Keep text snippets handy

Add and edit labeled Quick Access entries yourself, then copy a saved item. This is a managed snippet list, not automatic clipboard history.

Quick Access snippets

Control supported music players

Use playback controls with Apple Music, Spotify, or Kaset for YouTube Music. Player automation permissions are required; seek and Like controls vary by player.

Supported music controls

Run a focus timer

Choose a Pomodoro preset or configure focus length, break length, and cycles. Phase behavior depends on the Auto-Start Breaks setting.

Pomodoro timer setup

Browse supported sports

Enable a league, browse Past, Today, Upcoming, and Standings, and star teams or pin a match. The supported leagues are listed in the guide.

Supported sports and match workflow

Requirements and data boundaries

NotchDock currently requires macOS 14 or later and is free during the current beta. Some widgets make network requests to their data provider; the Stocks widget sends ticker searches and quote requests to Yahoo Finance. Music controls use macOS automation permissions, and some player artwork may be fetched from a supplied URL. Review the individual feature pages for setup and details.

NotchDock is designed for MacBooks with a display notch. Widget visibility and controls can be adjusted in their settings. It does not disable macOS notifications across the system.
